# Data

The CSVs are not included in this repository, because the dunnhumby licence does not allow republishing them.

To run the project, download *dunnhumby - The Complete Journey* from Kaggle and put these files in this folder:

- `transaction_data.csv`
- `hh_demographic.csv`
- `product.csv`
- `campaign_table.csv`
- `campaign_desc.csv`
- `coupon.csv`
- `coupon_redempt.csv`

`causal_data.csv` is not used.

Everything in this folder except this README is ignored by Git.
